# TabWise

TabWise 是一个本地优先的 Chrome/Edge 页面与任务记忆扩展。你可以保存工作目标和进度，用选定资料生成 AI 续接草稿，返回任务后按需恢复页面。扩展也会将符合安全条件的闲置页面替换为本地休眠页；点击休眠页或刷新标签页即可恢复原页面。

## 从哪里开始

侧栏工作台按使用场景分为四个入口：

| 入口 | 适合做什么 |
| --- | --- |
| 任务 | 记录目标与进度，选择资料，用 AI 生成和审阅续接草稿 |
| 页面 | 查找之前看过的页面、管理工作区、按 AI 主题整理 |
| 资源 | 查看安全休眠候选、资源预算与按需诊断 |
| 记录 | 查看恢复/批量任务、最近关闭、时间线与撤销 |

切换入口会保留未保存的编辑、页面搜索、资料勾选和 AI 草稿；更改任务内容仍需先保存再生成。工作区的筛选与低频操作分别收在「筛选与整理」和「更多」。任务的复制、下载、归档及删除收在「导出与交接」。

点击扩展图标默认打开标签列表，快速整理和保存找回有独立入口；点击「工作台」进入侧栏。设置按「AI 模型、休眠与资源、站点规则、数据与备份、隐私与诊断」分类，底部持续显示保存状态；格式错误会自动定位到对应控件。侧栏按 `/` 可直接查找页面，`Cmd/Ctrl+K` 打开命令面板，分类导航支持方向键及 Home/End。

工具栏弹窗使用固定的 410px 固有宽度，不受初始弹窗视口反向压缩。`npm run test:popup` 验证浏览器实际创建的 action 弹窗，包括点击、搜索、预览、保存及重新打开；`TABWISE_BROWSER=msedge npm run test:popup` 在 Edge 执行相同验证。

## 统一查找页面

在「页面 → 查找页面」中统一搜索打开的标签页、休眠页、工作区、恢复点、最近休眠与关闭记录。点击「近两周浏览历史 → 开启」，允许浏览器历史权限后，也会纳入浏览器已有的最近 14 天记录，包括安装 TabWise 之前访问过的网页。点击「浏览器书签 → 开启」后，书签栏和书签文件夹中的普通网页也会纳入本地搜索。

支持标题、域名、网址、中文拼音与英文纠错；同一完整网址合并展示所有来源，保留不同 fragment 的页面。点击结果优先切换已有标签页或恢复休眠页。未输入关键词时展示页面列表，每页 30 条，可按来源、状态、窗口、工作区、域名和时间筛选，并按相关度、最近访问或常访问排序。可把当前筛选保存为常用筛选。

结果可用上下箭头选择，Enter 打开，Cmd/Ctrl+Enter 后台打开；当前打开页面还可直接固定。选择一个进行中的任务后，点击「加入任务」会重新核对页面状态，仅把用户明确选择的标题和网址加入资料。任务资料页可按现有资料的域名推荐相关的已打开页面。

任务可记录优先级、截止日期、完成状态待办和默认工作区；需要时可从任务资料页按需打开绑定工作区。归档任务仍需用户主动执行；归档后会生成本地可审阅的交接清单，汇总目标、进度、下一步与资料，不会自动关闭页面或移动工作区。

「任务 → 证据问答」只使用用户选择资料的标题、域名、手动笔记和手动片段。每次提问先预览发送给模型的内容，回答必须附资料编号和待核对项；用户审阅后才保存到任务。它不会自动读取网页正文、唤醒休眠页或执行任何浏览器操作。

历史只读取 HTTP/HTTPS 网址、标题、访问时间和访问次数，在内存中最多缓存 60 秒，近两周最多纳入 10,000 个网址；达到上限会显示提示。书签只读取标题、网址和文件夹名称，同样只在内存中缓存。可在「历史隐私与缓存」排除特定域名或清空内存缓存；这些操作不会删除浏览器历史。历史与书签数据不写入扩展备份、同步或 AI 输入，搜索不加载网页。关闭任一来源会清空对应缓存并释放权限；删除原始浏览器记录或撤销权限后，列表刷新且旧结果无法再打开。

`npm run test:history` 验证安装前历史、14 天范围、来源合并、分页、已打开页切换、删除与撤权、重启，以及 320/420px 深浅主题。无头测试在隔离配置中预置真实历史权限，并模拟拒绝分支；原生授权弹窗需手动验证。`TABWISE_BROWSER=msedge npm run test:history` 在 Edge 执行相同验证。

## What the MVP includes

- 可配置闲置时长，默认 30 分钟
- 站点独立闲置阈值、标签临时保护 1 小时或当前浏览器会话
- 两种自动策略：默认保守模式和可选智能保护模式
- 批量休眠、暂停 1 小时、搜索与状态筛选
- 最近休眠记录与单条撤销
- 统一最近操作：撤销标签分组、保存/归档/固定工作区和休眠，冲突项显示原因
- 每 30 分钟自动创建本地恢复点，也可手动保存当前状态
- 保护活动、固定、播放音频、加载中、非网页、永不休眠及未知页面
- 本地休眠记录、重启后占位页重绑定和重复操作保护
- 本地智能整理：按域名分组、精确重复 URL 提示、工作区快照
- Side Panel 页面记忆：用标题、域名和 URL 路径模糊查找打开页、休眠页、工作区、恢复点和可选的近两周浏览历史
- 搜索精确打开命中的单页；工作区和恢复点支持勾选恢复、跨窗口去重及分批加载
- 完整会话布局：窗口、标签顺序、固定/活动状态、原生标签组名称/颜色/折叠状态和休眠状态
- 界面实时同步浏览器变化，保留搜索、工作区编辑和 AI 建议的选择
- 本地中文分词、拼音/首字母、英文拼写纠错，以及来源/窗口/状态/工作区筛选
- 最近关闭找回、快照增删与布局对比，勾选恢复缺失页
- 工作区重命名、成员编辑、保留来源的去重合并和可撤销回收站
- 工作区标签、仅本机备注、收藏排序与保存筛选
- 记忆工作区恢复方式、批次大小、布局和去重选项；按页面标签选择恢复
- 重复标签合并预览、主动选择链接检测、搜索关键词高亮与收藏快捷入口
- 关闭、低频或普通后台采样，按页面数量与界面活动调整频率
- 恢复任务中心：逐页进度、停止后续批次、失败与中断任务安全重试
- 按需恢复：先建立本地休眠页，点击后才请求原站；每批页数可选 1–5
- 备份下载时间、可关闭的提醒与独立恢复演练记录
- 本地休眠次数、加载完成延迟和休眠前 JS 堆采样统计
- 当前窗口关联工作区、更新差异预览、最近 5 个旧版本回退
- 可选网页数量与 JS 堆预算、持续增长提示及确认后的安全回收
- 大量标签分页、活动变化复用搜索索引、高频元数据合并写入
- 分钟级定时巡检、离线后补跑一次、失败/中断记录及手动重试
- 地址栏搜索：输入 `tw` 后跟查询词；也可用 `Cmd/Ctrl+Shift+K` 打开侧栏
- 可解释的休眠候选、两种节能策略，以及可选的本地关联术语搜索
- 可选浏览器内置 AI、本机 Ollama 或 OpenAI 兼容 API：选择范围、预览接收方与输入、编辑建议后确认应用
- 任务记忆 V1：目标、进度、用户确认记录、未决问题与下一步，跨重启本地保留
- 选定资料及手动笔记/片段、可编辑且有出处的 AI 续接草稿、Markdown/JSON 上下文导出
- 返回任务与选择资料恢复分开操作，支持按需加载及已有页面去重
- 不自动调用模型、不自动采集页面正文或遥测；云端 AI 仅接收用户预览后主动发送的任务输入

主题整理使用选定页面的标题、域名和状态；任务续接还使用用户明确记录的进度、确认记录及选定资料的手动笔记/片段。模型仅在点击生成时运行，建议不会自动执行标签操作。

## 真实 AI 接入（V2）

在设置页「AI 模型」中选择提供方。Ollama 填写本机地址与已安装的模型名，点击「模型自检」再保存设置。OpenAI 兼容 API 需自行填写基础地址、模型名和必要的密钥；地址填到服务规定的基础路径，不需要 `/chat/completions`。远程接口使用 HTTPS，本机 HTTP 需明确端口。代码不包含预设服务地址、模型名或密钥，新安装时地址和模型字段为空；具体可用模型以服务列表和自检为准。

2026-11-08 已用真实方舟模型验证插件自检、带引用的任务续接、修改采纳、导出及主题整理；单次任务生成约 36.5 秒。测试使用独立配置与合成资料，密钥未写入源码或验证文件。

兼容 API 的密钥默认保存在扩展的当前浏览器会话，浏览器退出后消失；只有勾选「在本机记住密钥」才存入未加密的扩展本地存储。密钥不回填到输入框、不进入设置对象、工作区备份、同步、任务导出或诊断；真实内容脚本无法读取密钥存储。留空保留原密钥，「清除密钥」立即移除。密钥绑定具体基础地址；换服务时需填写新密钥或先清除旧密钥。本机无认证服务可留空。

「保存模型配置」只保存配置；「读取模型列表」保存当前配置后访问该服务的 `/models`；「保存并自检」保存配置并发送只包含 `{"ok":true}` 的合成 JSON 推理请求，可能产生服务费用。任务内容不会参与自检。服务不支持 `response_format` 时可关闭「请求 JSON 模式」，本地仍严格校验生成结果。兼容接口采用非流式 Chat Completions；不支持只有 Responses API、工具调用或无文本返回的接口。

任务续接和主题整理共用接入层，生成前展示接收方及清理后的输入。更换提供方、地址、模型、JSON 模式或密钥后，旧预览无法继续生成，缓存也不会跨配置复用。响应最多 1 MiB、生成最多等待 90 秒，续接最多请求 2400 输出 tokens，主题整理最多 1600；拒绝截断、未知引用与额外动作。401/403/429、网络失败和超时显示可处理的原因，不回显服务错误正文，不自动重试付费请求。停止生成会中止请求并拒绝迟到结果，远端服务是否停止计算或收费取决于其实现。

主题标题和整理目标也会清理网址、邮箱和常见凭据。完整原始标题留在本地，用于保存和执行前核对页面身份；模型看到的内容与预览一致。设置加载完成后才能编辑，避免初始配置覆盖刚选择的提供方。

## 任务记忆与 AI 续接

打开侧栏「任务」，点击「新建任务」，记录名称、目标和进度。创建后在「记录进度」补充用户确认记录、未决问题和下一步，「任务资料」选择本次需要的页面，「AI 续接」预览和生成草稿。每个任务最多 20 个资料，最多保存 20 个任务（包括归档），任务数据合计最多 2 MiB；容量或存储写入失败会显示原因，已有任务保持原样。

点击「选择资料加入任务」，选择当前窗口或已保存工作区，再读取列表、逐项勾选并确认加入。列表支持分页和搜索，每次最多选 20 个；相同完整网址只保留一次。隐私窗口与浏览器内部页面不参与。预览不打开页面，加入前重新核对所选页面或工作区成员的标题、网址和身份；变化后必须重新读取。任务仅保存持久网址与资料编号，不持久保存浏览器标签 ID。

每份资料可手动填写笔记和片段。勾选本次交给 AI 的资料（默认不选），保存编辑，再点击「预览续接输入」。预览展示完整任务输入、所选资料以及所选模型、服务地址。模型不接收原始完整网址；网址、邮箱和常见凭据模式会被清理，其他私密内容仍需要你在预览时检查。网页标题与域名不能证明正文事实，扩展不自动提取或扫描正文。

点击「生成续接草稿」后，可以修改摘要、待验证判断、问题和下一步的文字，点击资料引用回到出处。明确勾选已审阅并「确认采纳草稿」，才将其单独保存为 AI 建议；用户确认记录不会被模型覆盖。JSON 格式、快照编号与所有引用均经本地校验，额外工具动作或未知引用会被拒绝。任务内容修改后，已采纳的建议标注「输入已变化」。输入预览 10 分钟有效；取消、编辑输入、切换任务、关闭侧栏或 worker 重启会使进行中的草稿失效，不自动重试或保存迟到结果。

下次点击任务名称会显示已保存的进度与建议，不打开资料。「选择资料继续」进入独立恢复预览，可取消页面、跳过已打开页、选择 1–5 页批次或按需加载；确认后复用持久恢复任务账本，执行前核对资料内容。按需模式先建立本地休眠页，点击后才加载原站。恢复的是网址，不是未保存的表单、文档内容或登录状态。

「复制 Markdown」和「下载 Markdown」生成带出处的上下文包，可手动交给其他 AI 对话或 IDE；「导出任务 JSON」下载完整任务记录。这些本地导出包含原始网址和用户笔记。复制被浏览器限制时可改用下载。暂不提供任务 JSON 导入或跨设备任务同步；现有工作区备份不包含任务记忆，请通过任务导出另行保留。任务保存在仅扩展可信界面可访问的本地存储；归档保留数据，删除必须明确确认。

## 可核对的 AI 主题建议

在侧栏「页面 → AI 整理」中选择当前窗口、已保存工作区或手动勾选页面，点击「预览分析输入」。这里展示完整的页面元数据输入及接收方；生成时使用同一份快照，不重新扩大分析范围。每次最多 20 页、最多 3 个主题；超出范围会提示缩小选择，不会静默截断。私密窗口和浏览器内部页面不参与分析，休眠页及已保存工作区不会因分析而打开。

「生成主题建议」会返回主题名、具体页面成员及基于标题/域名的归类依据。你可以改名、取消成员，再逐项确认「建立标签组」或「保存为工作区」。保存保留 URL 与原始标题，不关闭当前标签；工作区输入只能保存，不会自动打开页面来分组。原生分组要求同一窗口内至少两个非活动、非固定且未播放音频的普通网页。

所有提供方均校验 JSON schema、快照编号及页面成员，拒绝未知、重复、跨主题或额外动作字段。输入快照 10 分钟有效，只保存在浏览器会话中；关闭、重新加载、导航、标题变化或移窗后，旧成员不能应用，需重新预览并生成。应用接口只对发起分析的扩展侧栏文档开放，同一主题的同一动作不能重复执行。

设置中可以选择浏览器内置模型、本机 Ollama 或兼容 API。模型不可用或输出格式不合规时会显示原因；本地搜索和 Popup 的按域名整理仍可用。「结构已校验」表示格式和成员有效，归类依据仍需用户核对，不代表已经验证页面正文或模型推断。

设置中的「模型自检」使用表单中的地址与模型，读取已安装模型及 completion 能力，并从扩展来源执行小型 JSON 推理。通过后展示耗时和扩展来源；列表中不支持生成的模型无法选择。自检不发送网页数据，也不自动保存表单。浏览器模型自检先检查可用状态，未准备好的模型不会触发下载。

若自检或生成返回 403，在 `chrome://extensions` 查看 TabWise 的扩展 ID，退出原来的 Ollama 服务后以允许该来源的方式启动：

```bash
OLLAMA_ORIGINS='chrome-extension://<TabWise 扩展 ID>' ollama serve
```

将占位符替换为实际 ID，Ollama 地址仍保持本机 loopback。若服务提示模型不支持 generate，请改用模型清单中包含 `completion` 能力的模型；已有模型文件并不保证与当前 Ollama 版本兼容。

结构化主题请求通过 `think: false` 让支持该选项的本地模型直接输出 JSON，避免将有限输出预算消耗在思考内容上；仍会对返回结构和页面成员执行本地校验。生成和自检推理最多等待 90 秒，连接检查最多等待 30 秒；超时不会应用建议。

生成期间可以点击「停止生成」。切换范围、修改目标、刷新/关闭侧栏也会取消请求；Ollama HTTP 请求会中止，浏览器模型会停止并释放会话。取消后的输出不能再通过接受或应用接口；模型服务自身是否立即停止底层计算取决于其取消实现。

建议缓存仅保存在当前浏览器会话，最多 10 条、5 分钟有效。缓存键区分提供方、地址、模型、密钥版本、JSON 模式、目标和完整元数据成员；不保存完整 URL 或浏览器标签 ID。命中后绑定新快照和新成员编号，再检查实时页面状态，界面显示「缓存 · 已重新校验」；「清空建议缓存」可强制下次重新推理。

## 最近操作与撤销

侧栏「最近操作与撤销」保留本次浏览器会话最近 20 条操作；后台 worker 重启仍保留，浏览器重启后清空，避免旧标签/分组 ID 被复用。标签分组撤销会恢复原分组、名称、颜色、折叠状态和标签顺序；如果窗口内的页面、分组或顺序已经变化，就跳过该窗口。工作区保存撤销仅移除仍与保存时完全一致的新工作区，不关闭标签；归档、取消归档和固定状态也可撤销。休眠撤销复用原有恢复机制，已导航或关闭的页面不会强制重开。

每条撤销只执行一次，显示恢复成功项和冲突原因；执行中断的记录不会自动重放。撤销不能恢复网页内未保存的表单或运行状态。保存达到 20 个工作区上限时会拒绝新保存，避免覆盖旧工作区。重命名、成员编辑和移入回收站也纳入统一撤销。

## 选择性恢复与工作区管理

点击搜索结果只打开该条记录对应的页面；如果同一完整 URL 已在任一窗口打开，则聚焦已有标签，休眠页先恢复。保存的成员索引与 URL 必须仍匹配，过期结果需重新搜索。

侧栏和 Popup 中的工作区与恢复点提供恢复预览，可以全选、全不选或逐页勾选。默认跳过所有窗口中已打开（包括休眠）的相同 URL，也会去重所选页面；取消该选项可明确打开副本。每批最多 5 页，等待加载完成后继续，单页等待最多 8 秒，超时显示“仍在加载”，后续批次继续。每页有成功、跳过或失败结果。预览只在当前界面文档、当前浏览器会话有效，5 分钟过期；执行前校验保存内容，预览只允许执行一次。恢复的是保存的网址，不能还原网页进程、表单或登录态。

工作区可重命名、取消成员、固定或归档；勾选多个工作区后可合并，原工作区保留。布局快照合并保留窗口边界、重复页面、组信息和来源历史；旧版纯网址列表合并仍会去重。搜索打开成员和确认恢复都会更新最近打开时间。移入回收站仅改变本地快照，不关闭标签，也不参与搜索、AI 分析或自动归档。回收站最多 20 个，满额时拒绝继续移入；可恢复或在明确确认后永久删除。恢复及撤销也遵守 20 个有效工作区上限。备份导出只包括回收站之外的工作区，导入容量不足时拒绝整批导入，不覆盖现有工作区。

编辑工作区时可添加最多 12 个标签（每个 30 字）、2000 字备注和收藏状态；收藏优先排序。列表可按名称、页面、标签和备注搜索，按标签、收藏或归档状态筛选，最多保存 10 个筛选条件。备注与筛选仅保存在本机，随本地备份导出；主动同步会同步工作区网址、标签、名称及收藏/固定/归档状态，备注不进入同步，采用远端版本也保留原有本机备注。名称、标签和收藏变化参与同步冲突比较；这些字段及备注修改会使内容预览失效，最近打开时间和恢复时自动取消归档不使内容预览失效。

每个保存页面可单独设置标签，恢复预览按页面标签勾选，也可继续手动调整。默认记住工作区的加载方式、1–5 页批次大小、布局、跳过已有页面和标签选择；只记忆选项，不自动恢复。预设及页面标签随备份和主动同步保留。列表提供收藏快捷按钮，命令面板优先展示收藏。搜索页面、工作区及分页列表对直接命中的关键词做安全高亮。

「合并当前窗口重复页」预览同一窗口中完整网址完全一致且通过当前保护策略的重复页面，每组保留一页；活动、固定、播放音频、临时保护或保护状态未知的页面不会列为可关闭项。可取消勾选，确认后重新检查保留页与待关闭页的网址、导航版本、活动和保护状态，变化项跳过。关闭预览只执行一次，不跨窗口关闭页面。

工作区「检测链接」先列出保存的页面，默认不选；明确选择 1–50 页后点击检测，才向这些网站发送最多并发 3 个、每项最多 5 秒的 HEAD 请求。请求不携带登录凭据，不打开页面、不读取正文、不自动删除保存内容。404/410 标为失效；401/403 或登录跳转显示需登录；离线、超时、服务错误及不支持 HEAD 均不判定失效。保存内容变化后须重新预览。

主动同步先预览并选择云端副本中的工作区，未选内容保留在本机；当前快照、页面标签、恢复预设与四类站点列表参与同步，本机备注、历史版本和合并来源不上传。每个分块约 6 KB，一次内容上限 45 KB，为旧版本与新版本同时保留空间。先写完整分块及 SHA-256 校验，再切换版本清单；容量不足、分块未到齐或预览后内容变化时拒绝覆盖。同步成功后工作区、设置及历史一次性写入本机；本机最终写入失败保留准备记录，重新预览确认后可以完成该版本，不自动重复创建冲突副本。兼容原单项元数据格式。浏览器云同步仍有传播延迟，远端分块未完整到达时应稍后重试；版本检查不提供跨设备的全局锁。

## 备份完整性

新版 JSON 备份使用规范化 SHA-256 校验及页数、窗口、组和历史版本计数，保存工作区布局、休眠状态和最近 5 个版本。导入先预览，不修改存储；相同内容默认跳过，也可保留副本。ID 冲突生成新副本并记录来源，设置需单独勾选才导入。确认时重新检查当前工作区与容量，工作区和设置一次性写入；存储失败保留原数据并允许重试。

旧版无校验备份仍可导入，会显示提示和无效页面计数。上限为 8 MiB、单个快照 5000 页、工作区及历史合计 50000 页、20 个有效工作区；超限明确拒绝，不截断页面。SHA-256 用于检测内容变化，不提供签名或加密。

可选 AES-GCM 加密使用 PBKDF2-SHA256，默认 310000 轮；旧加密备份仍可读取，并提示重新加密。密码仅用于当前操作，不保存。生成备份 JSON 不记录已下载，设置页发起下载后才记录时间；浏览器下载请求不能证明文件已成功写到磁盘，请自行核对。提醒默认关闭，可选 7/30/90 天，在设置和侧栏显示，不发送通知或自动导出。

「恢复演练」读取并解密所选文件，校验结构、完整性和数量，仅写入演练结果摘要；不导入工作区或设置、不打开网页。最近 20 条下载/演练记录仅保留时间、成功与校验状态、数量及是否加密，不保存文件内容、文件名或密码。普通导入预览仍不写入数据。

## 统一批量任务与命令面板

任务中心统一显示恢复、批量休眠、分组和预算回收。休眠和回收每批最多 5 页，分组按窗口逐个执行；可停止、查看每项结果并重试失败或未完成项目。恢复任务保留最近 10 项，批量任务另保留最近 10 项；进行中的批量记录不能被后续任务挤出。后台重启标记中断，执行结果不确定的项需手动检查，不自动重放。

批量休眠和分组先显示可分页的选择预览，确认时保留原目标身份，执行前重新检查网址、活动、保护及分组布局；变化项跳过。成功项生成一次整体撤销；分组原布局在操作前保存，记录写入失败时不执行该窗口。预算回收共用任务队列及原有闲置与网页保护检查。

Popup 和侧栏点击「命令」或按 `⌘K` / `Ctrl+K` 打开命令面板。支持方向键、Enter、Escape、焦点返回和本地页面搜索；可保存恢复点、填写工作区名称、打开工作区恢复预览、休眠/分组预览、预算预览、撤销最近操作及打开设置。搜索结果有数量限制，旧请求不会覆盖新输入。快捷键在 TabWise 界面内生效；浏览器任意页面打开侧栏仍使用既有的 `⌘⇧K` / `Ctrl+Shift+K`。

## 自动化运行记录

巡检时间精确到分钟，以本机日历计算下一次单次 alarm。浏览器错过运行后，在启动或下一次分钟检查时最多补跑一次。最近 20 条运行记录保存状态、阶段、恢复点数量、已归档数量、耗时和错误；副作用前先记录运行状态。已运行的定时槽位，包括失败槽位，不自动重放；后台重启时未完成记录标为“后台中断”，可检查后手动重试。重试建立新记录并关联原记录，同一失败记录只允许发起一次重试；若再次失败，可重试新的失败记录。

## 恢复任务中心

Popup 和侧栏分别保留最多 10 个恢复任务和 10 个批量任务，进行中记录优先保留，恢复最多同时排队 5 项。确认恢复后立即返回任务编号，关闭界面后继续执行；任务及打开意图先写入本地账本，再镜像到会话存储，随后创建窗口和标签。每批可选 1–5 页，停止会等待当前批次结束，后续页面保持未完成状态。详情每页显示 50 条结果。已结束任务可归档隐藏，并通过「显示已归档」查看；归档任务占用保留容量。

后台 worker 或浏览器重启会把未完成任务标记为中断，不自动重放。打开结果不确定的页面标为“需要重新检查”；手动重试只选择失败、已关闭或未完成页面，再检查保存来源和所有窗口的逻辑网址，默认跳过已存在页面。重试会生成关联原任务的新记录，原记录不再重复计入健康状态。浏览器退出后本地账本保留，但重新启动会清除旧标签/窗口绑定；批量操作只保留摘要，必须重新预览当前页面，恢复任务可以重新校验保存来源后继续。

恢复预览可选择「先建立休眠页，点击再加载」。此方式适用于布局快照及旧网址列表，先创建空白标签、持久化原网址记录，再导航到本地休眠页；不会请求原站。停止和重试保留加载模式与批次大小，不计作成功休眠网页的效果数据。

重试与继续执行把父任务的后续任务编号和新任务一起写入账本，同一父任务只允许一个后续任务。多界面同时确认时只接受一个；旧任务显示后续任务入口，不再提供重试按钮。新任务仍可在失败后创建自己的后续任务，后台重启不自动重放任何已预约的副作用。

## 工作区增量更新

在工作区中点击「关联当前窗口」，再点击「更新预览」。预览显示相对保存内容的新增、移除、标题及布局变化；确认时重新检查窗口、关联和工作区内容，变化后需重新预览。更新保留原工作区编号、名称和固定/归档信息，仅替换保存的页面及布局，不关闭标签。

每次增量更新或版本回退保留旧内容，最多 5 个历史版本。「历史版本」支持先看差异再确认回退，回退也保存当前版本。关联仅在当前浏览器会话有效，旧版本保存在本地工作区中；这些更新也可通过最近操作撤销。

## 资源预算

在设置中开启预算提醒，默认网页数量预算为 50 页、已采样 JS 堆预算为 1024 MB。网页数量只计普通、非无痕、尚未休眠的网页；堆预算仅计最近 5 分钟的有效采样，并显示覆盖数量及最早采样时间。未采样页面不按零内存推断，JS 堆不代表浏览器物理内存。

持续增长提示要求同一网址和文档连续 3 个不同时间的采样均增长，累计增长至少 64 MB；新增采样覆盖不计为页面增长，导航或关闭会清除历史。提示只说明采样趋势，不能证明内存泄漏。

超出预算后可预览安全回收候选，勾选后确认休眠，每次最多 50 页。候选必须通过当前保护策略和网页保护检查，并达到闲置阈值；活动、固定、播放音频、未保存编辑、上传、加载中和保护状态未知的页面均排除。执行前和休眠前再次检查网址、文档版本、设置、活动及保护状态，变化项会跳过。使用智能保护模式可获得网页保护状态。预算功能本身不自动休眠或关闭页面。

站点独立闲置阈值在设置中以「域名 分钟」填写，最多 100 项，范围 5–1440 分钟，最具体的子域名优先；仅本机与备份保留，不参与跨设备站点列表同步。自动休眠、候选及预算回收共用阈值。临时保护优先于直接/批量/自动休眠，可设为 1 小时或当前浏览器会话；导航到另一网址、关闭标签或浏览器退出后失效，也可手动解除。

侧栏休眠效果显示最近 30 天、最多 200 次成功操作的本地记录：实际休眠次数、恢复次数、从恢复请求到浏览器报告加载完成的平均延迟。休眠前 JS 堆采样只采用同网址最近 5 分钟的值，显示覆盖次数与合计；它是历史采样证据，不是实际释放的物理内存或电量节省，同页多次休眠可被重复计入。按需创建休眠页不计作卸载网页。记录不含标题、网址或浏览器标签 ID；「清除本地历史」同时清除效果记录。

## 大量标签性能

Popup 标签列表、恢复选择、工作区编辑与更新差异、快照差异、批量预览、AI 手动页面选择和资源诊断每页最多渲染 50 条。跨页和筛选后的勾选保存在独立状态中，提交完整选择；「选择全部页」和清空作用于全部列表。AI 手动选择最多 20 页，仅在选择该范围时挂载列表。实时刷新复用带身份的 DOM 节点，保留输入草稿、焦点、展开状态和滚动位置。整理建议最多展示 12 项，展开成员最多 50 页；侧栏搜索通过后台检索完整索引，再返回有限结果。

快照构建和差异对比使用窗口、分组和重复网址映射，避免逐页扫描全部列表。只有标题、域名或网址变化才重新编译中文/拼音搜索数据，活动、状态、窗口等变化更新结果元数据；并发搜索共用正在进行的索引构建。标签元数据更新按 100 ms 合并最新值，关闭标签前立即写入待处理更新；未变化数据不重复写入。

`node test/performance.mjs` 使用 300/1000 页确定性元数据测量快照、索引和查询耗时，不会打开真实网页。浏览器回归另验证 1000 条仪表盘数据下每页 DOM 的数量，以及真实页面的停止、重试、保护和版本回退流程。

`node test/browser-performance.mjs` 用独立配置对比不启用扩展与启用 TabWise/侧栏的真实 Chromium，每种模式运行 3 次，每次加载 12 个本地合成网页，报告页面堆、进程数、启动与加载 CPU 时间以及界面请求延迟。RSS 不可获取时返回 `null`；即使可获取，进程 RSS 相加也可能重复计算共享内存。这是该场景的扩展成本测量，不代表实际网站的电量收益。E2E 覆盖完整浏览器关闭/重开；等待失败时在系统临时目录保存截图、任务、健康状态和脱敏诊断，每项采集有超时。

## 会话布局、最近关闭与对比

新保存的工作区和恢复点使用布局快照，记录普通网页所在窗口、页内顺序、固定与活动状态、标签组名称/颜色/折叠状态及休眠状态；休眠页保存原始网址，内部页面和无痕页不纳入。窗口和分组使用快照内编号，不持久化 Chrome 标签/窗口 ID。只对相邻的相同恢复点去重，A → B → A 的会话变化仍保留。

恢复预览默认勾选「新建窗口恢复布局」，只给实际新开的页面创建窗口、恢复顺序和分组，已存在页面保持原样。新恢复的休眠页直接打开本地占位页，不访问原站。取消布局选项后，所选网页在当前窗口加载。仅选择部分页面时，顺序压缩为所选页的相对顺序；Chrome 对固定页、活动页和标签组的限制仍适用，布局失败会显示原因。旧版网址列表仍可恢复，工作区 JSON 备份导入保留有效布局。快照不能还原网页进程、表单、滚动位置或登录会话。

Popup 和侧栏中的「最近关闭」默认开启，最多保留 100 条标题/网址，默认 7 天，设置中可改为 1–30 天；无痕页面不记录。关闭记录跨扩展后台重启保留，过期记录在读取时从本地存储清理。可用标题、拼音、首字母或网址找回，优先复用已打开的相同网址，成功后移除记录。可以清空列表，关闭此功能也会清空已有记录。不读取浏览器全局历史记录，不需要新增 history/sessions 权限。

「快照对比」选择基准恢复点和当前会话或另一恢复点，显示新增、缺失及窗口/分组/固定/活动/休眠状态变化。相同网址的重复出现按数量比较；只勾选想找回的缺失页面，再打开恢复预览。对比结果显示生成时间，恢复前重新校验基准内容与当前已打开页面，避免重复恢复。

打开的 Popup 和侧栏通过浏览器事件合并刷新，隐藏后断开订阅，显示或后台重启后重新连接；不会额外轮询后台。刷新保留表单草稿、勾选、搜索筛选、恢复预览和 AI 主题编辑，执行仍需原有快照校验。存储中的读改写按区域串行，避免同时休眠、关闭或保存时丢失条目。

## Page memory and search

TabWise indexes locally available metadata from open and suspended tabs, saved workspaces, recovery checkpoints, and recent suspensions. Search never wakes suspended pages or reads page text. Results favor directly open pages, then suspended pages, then saved snapshots.

Side panel search supports Chinese word segmentation, full pinyin and initials (using the vendored MIT-licensed pinyin-pro 3.29.5), plus bounded English typo matching. Filters combine source, status, current browser window and saved workspace. Identical complete URLs are merged after filtering, with all matching sources shown; fragments remain distinct. Metadata is compiled incrementally and invalidated on browser/storage events, with a one-minute freshness bound for expired closed entries. Older asynchronous responses cannot overwrite a newer query.

Enable "本地关联搜索" in Settings to expand a small built-in set of technical terms such as front-end, performance, browser, database, and design. This is a local lexical association feature, not a cloud model or full-text page search.

Use `tw <keywords>` in Chrome's address bar to search. The first result can be opened with Enter; side panel search shows all matching sources and always uses the normal restore flow.

## Page memory diagnostics

设置可选关闭、低频或普通后台采样。普通模式每轮最多 25 页，超过 200 个合格页面时降为 15 页，并发最多 4；界面活动时最短 1 分钟，后台为 2–3 分钟。低频模式每轮 8–12 页、并发最多 2，间隔 3–5 分钟。最近活动且未重新采样的页面优先取最多 4 页，其余名额持续轮转，避免饿死旧页面。关闭后不做后台采样，手动资源诊断仍可请求测量。

Automatic idle checks rotate across at most 50 tabs. Untouched samples remain available while closed, discarded and navigated tabs lose stale samples; navigation revisions reject measurements from a changed document even if it returns to the same URL. The dashboard displays measured/eligible coverage and the latest session-only value in each tab row; those values come from different sampling times. Explicit diagnostics may refresh all eligible pages with bounded concurrency. 为保持稳定版 Chrome 的安装兼容性，诊断使用网页 JavaScript 堆采样，不申请仅开发版可用的 `processes` 权限。

## Production safeguards

TabWise upgrades local storage through an idempotent schema migration on installation and browser startup; existing settings, workspaces and restore records are preserved. The settings page can export a bounded, redacted local diagnostic summary and clear local history, resource samples and AI cache without deleting settings, workspaces or active suspension restore records. Diagnostic summaries exclude page titles, complete URLs, form data and cookies.

Recovery previews show the selected page count, already-open pages that will be skipped by default, suspended pages that will remain suspended and the intended window count. The GitHub Actions workflow runs unit tests, syntax checks and isolated Chromium extension regression tests on pull requests and `main` pushes.

休眠前持久化原网址和恢复模式。存储距容量上限不足约 128 KiB 时拒绝新休眠，页面保持原样。浏览器已切换到休眠页或已卸载原网页后，状态、统计或历史写入失败也保留最初的恢复记录；无法判定浏览器操作结果时同样保留记录供检查，不盲目重放。只有确认浏览器未执行操作时才清理预约记录。

## Suspension modes

- **保守模式（默认）**：只自动休眠“可信网站”列表中的页面，适合对数据安全要求高的场景。
- **智能保护模式（可选）**：自动检查所有普通网页。页面出现编辑、文件选择或媒体活动时会保持保护；未获得网页保护权限或未完成检测的页面同样不会自动休眠。启用该模式时，浏览器会请求对网页运行本地保护脚本的权限；TabWise 只保存保护布尔状态，不读取表单内容。

## Energy strategies

- **深度节能（默认）**：将页面替换为本地休眠页；切回标签不会恢复，点击休眠页或刷新才恢复。
- **轻度节能**：使用 Chrome 的原生 tab discard；原 URL 保留，但切回标签会由浏览器自动重新加载。

## Load locally

1. Open `chrome://extensions` in Chrome, or `edge://extensions` in Edge.
2. Enable **Developer mode**.
3. Choose **Load unpacked** and select this `tabwise` directory.
4. Open the TabWise toolbar popup and use **Settings** to add trusted domains before enabling automatic suspension.

## Notes and limits

- 休眠页仍有少量扩展渲染开销，但原网页文档会被卸载，不能承诺零资源占用。
- Unknown pages are deliberately not suspended automatically. This avoids losing unsaved form data or interrupting web apps.
- 切回休眠标签不会自动恢复；点击休眠页内容或刷新标签页才会恢复原页面。
- Chrome 原生 discard 模式例外：切回标签时会自动恢复。
- Workspaces store URLs and titles locally and reopening them cannot restore in-page state, POST submissions, or unsaved edits.

`test:e2e` uses a temporary Playwright Chromium profile in headless mode. It does not open a browser window or use the user's Chrome profile. Before the first run, install the bundled test browser with `npx playwright install chromium`.

`test:edge` 使用已安装的 Microsoft Edge 和临时配置验证 MV3 后台、Popup、设置、侧栏、休眠恢复及带标签的按需恢复，不使用用户浏览器配置。Chromium 故障回归包含后台真实强制终止、离线、重复页预览过期、并发重试/续跑及同步选择界面；权限撤销通过运行时拒绝模拟，存储配额通过故障注入验证。Edge 冒烟验证不等同于完整 Chromium 用例或真实内置 AI 模型测试。

`test:context` 使用独立 Chromium 配置验证任务创建、明确选定资料、手动片段清理、两种假模型适配器、草稿编辑与确认、取消迟到响应、Markdown/JSON 下载、未保存编辑保护、归档、按需恢复和完整浏览器重启；真实内容脚本无法直接读取任务本地存储。设置 `TABWISE_E2E_ARTIFACT_DIR` 为已存在的目录，可保存浅色/深色 320px 截图。新增任务领域、草稿校验、持久化和后台模块可用 `node --experimental-test-coverage --test test/task-context.test.js test/task-context-ai.test.js test/context-manager.test.js` 检查覆盖率。

AI E2E 使用本地 HTTP 假模型和浏览器 API 假模型验证范围、预览、结构校验、编辑/确认、旧建议拒绝及不可用场景，同时验证真实分组撤销、状态冲突、HTTP 请求取消、缓存重绑定和模型自检失败路径；不代表真实模型的推理质量或特定 Chrome 设备上的内置模型可用性。校验模块覆盖率可用 `node --test --experimental-test-coverage test/ai-analysis.test.js test/ai-cache.test.js test/operations.test.js` 检查。
